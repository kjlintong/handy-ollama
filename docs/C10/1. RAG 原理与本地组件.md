# RAG 原理与本地组件

> **版本基线**：Ollama 0.17.x（示例实测通过）
> **章节定位**：理解 RAG 全流程与本地化组件选型。第 2~4 节是可运行的完整实战（LangChain / LlamaIndex / DeepSeek-R1 三种路线）。

## 一、什么是 RAG

RAG（Retrieval-Augmented Generation，检索增强生成）解决 LLM 的**知识时效性与幻觉问题**：不微调模型，而是**先检索相关资料，再让模型基于资料生成**。

```
用户提问
   │
   ▼
┌───────────────────────┐
│ 1. 加载文档             │  PDF/网页/笔记…
│ 2. 分块(Chunking)      │  每块几百 token
│ 3. 嵌入(Embedding)     │  文本 → 向量
│ 4. 存储(向量数据库)     │  Chroma/Milvus/Qdrant…
│ 5. 检索(相似度 Top-K)   │  问题向量 → 最相关分块
│ 6. 生成(LLM)           │  资料 + 问题 → 答案
└───────────────────────┘
   │
   ▼
基于检索资料的回答(可溯源)
```

## 二、本地 RAG 的组件选型

RAG 的每个环节都有本地化方案，**Ollama 独占其中两环**（嵌入 + 生成）：

| 环节 | 本地方案 | 说明 |
|---|---|---|
| 文档加载 | `unstructured` / `pypdf` 等 | 纯本地解析 |
| 分块 | LangChain / LlamaIndex 内置 | 本地算法 |
| **嵌入** | **Ollama + bge-m3（1024 维）** | 本地向量化 |
| 向量存储 | **Chroma**（入门）/ Milvus / Qdrant | 本地数据库 |
| **生成** | **Ollama + qwen3:8b / deepseek-r1** | 本地推理 |

**Ollama 双后端**的独特优势：一套服务（`localhost:11434`）同时提供 Embedding API 与 Chat API，无需部署第二套模型服务。

## 三、关键参数与调优

### 3.1 分块大小（Chunk Size）

- **块太小**（<100 token）：上下文碎片化，信息不完整；
- **块太大**（>1000 token）：检索粒度粗，混入无关信息；
- 经验值：**300~500 token，重叠 50**（常用默认），按文档类型微调。

### 3.2 Top-K 与相似度阈值

- `Top-K`（取回块数）：3~5 个块通常够用，多了稀释注意力；
- 相似度阈值：低于阈值（如 0.5）时**宁可回答"资料中未找到"**，避免硬凑答案。

### 3.3 嵌入模型选择

| 模型 | 维度 | 特点 |
|---|---|---|
| `bge-m3`（推荐） | 1024 | 中英文俱佳，支持多语言检索 |
| `nomic-embed-text` | 768 | 轻量、英文为主 |
| `mxbai-embed-large` | 1024 | 英文检索质量高 |

> 嵌入模型**不推荐量化**（精度敏感），用原版即可。

## 四、本地 RAG 的质量检查清单

一个"能跑"的本地 RAG 离"好用"还有距离，按此清单自查：

- [ ] 检索命中：随机抽 10 个问题，检查 Top-3 检索结果是否真的相关（**检索是 RAG 的地基**）；
- [ ] 上下文不超限：分块大小 × Top-K ≤ 模型上下文的一半；
- [ ] 回答有依据：模型回答应引用/呼应检索内容，而不是自由发挥；
- [ ] 无检索时行为：库外问题应明确说"不知道"，而非幻觉编造（用系统提示词约束）；
- [ ] 速度可接受：嵌入 + 生成全本地，一次问答应在数秒内完成（8B 模型）。

## 五、从基础 RAG 到进阶

第 2~4 节是三种基础 RAG 实战，进阶方向见[第5节 GraphRAG 与 Agentic RAG](./5.%20GraphRAG%20与%20Agentic%20RAG.md)：

- **GraphRAG**：用知识图谱提升多跳问答能力；
- **Agentic RAG**：让 Agent 自主决定"查什么、查几次、要不要换检索策略"；
- 两者都可以在纯本地环境用 Ollama 实现。

## 本章小结

- RAG = 加载 → 分块 → 嵌入 → 存储 → 检索 → 生成，**Ollama 同时承担嵌入与生成**；
- 组件选型：bge-m3（嵌入）+ Chroma（存储）+ qwen3:8b（生成）是最简本地组合；
- 调优三参数：分块大小（300~500）、Top-K（3~5）、相似度阈值；
- 质量清单：先查检索命中，再谈生成效果。
