# Ollama 安装与配置 - macOS 系统篇

> **版本基线**：Ollama 0.17.x（macOS,示例以 `qwen3:4b` 演示）
> **本节定位**：macOS 上安装 Ollama 并跑通第一个本地模型；Enchanted 提供图形化聊天入口。

本节完成 macOS 上 Ollama 的安装与配置,分三部分：官网下载、运行模型、安装 Enchanted 客户端。

## 一、访问官网直接完成下载

1. 访问官网主页

   > Ollama 下载：https://ollama.com/download
   > 
   > Ollama 官方主页：https://ollama.com
   > 
   > Ollama 官方 GitHub 源代码仓库：[https://github.com/ollama/ollama/](https://github.com/ollama/ollama)

   ![](../images/C2-1-1.png)

2. 等待浏览器下载文件 Ollama-darwin.zip，完成后双击该文件解压，双击解压后文件并将出现如下弹窗。

   ![](../images/C2-1-2.png)

   点击`打开`后会出现如下弹窗，我们点击`Move to Applications`即可。

   ![](../images/C2-1-3.png)
3. 安装完成后，可以右上角状态栏看到 Ollama 图标，点击 `Quit Ollama` 可以退出 Ollama 。

   ![](../images/C2-1-4.jpg)

## 二、运行 Ollama

- 终端命令启动

```bash
ollama run qwen3:4b
```
> 第一次启动需要下载对应模型文件，因此我们选择下载千问3的4b版本节省时间。可以点击官网右上角的 [Models](https://ollama.com/library) 获取 Ollama 支持的模型。

> 加载完成后可以在终端与模型进行对话，`/bye`结束对话。

![](../images/C2-1-5.png)

## 三、安装 Enchanted
Enchanted 是一款开源、兼容 Ollama 的优雅 macOS/iOS/visionOS 应用程序，是一款可以连接私人模型的 ChatGPT 应用程序 UI。可以在 [Enchanted](https://github.com/AugustDev/enchanted) 点击 App Store 进行下载。

![](../images/C2-1-6.png)

我们在运行 Ollama 之后，直接打开 Enchanted 就可以连接到 Ollama。

![](../images/C2-1-7.png)

## 本节小结

- 下载：官网下载 `Ollama-darwin.zip`，解压后拖入 Applications；
- 运行：`ollama run qwen3:4b` 首次启动自动拉取模型，`/bye` 结束对话；
- GUI：Enchanted（开源，macOS/iOS/visionOS）可直接连接本地 Ollama，无需额外配置。
