# 使用 DeepSeek R1 和 Ollama 实现本地 RAG 应用

> **版本基线**：Ollama 0.17.x + deepseek-r1:1.5b（与 [9.1 RAG 原理](./1.%20RAG%20原理与本地组件.md) 配套的实战章节）
> **本节定位**：DeepSeek R1 路线实战——用推理型模型完成本地 RAG，与 [9.2 LangChain 路线](./2.%20使用%20LangChain%20搭建本地%20RAG%20应用.md) 互为补充。

本文演示如何利用 DeepSeek R1 和 Ollama 构建本地化的 RAG（检索增强生成）应用，完整走完文档处理、向量存储、模型调用等关键步骤。本教程选用 `deepseek-r1:1.5b` 作为基础语言模型；考虑到不同模型各有特点与性能差异，读者可根据实际需求换用其他模型。

> 注: 本文档包含核心代码片段和详细解释。完整代码可见 [notebook](https://github.com/datawhalechina/handy-ollama/blob/main/notebook/C7/DeepSeek_R1_RAG/%E4%BD%BF%E7%94%A8%20DeepSeek%20R1%20%E5%92%8C%20Ollama%20%E5%AE%9E%E7%8E%B0%E6%9C%AC%E5%9C%B0%20RAG%20%E5%BA%94%E7%94%A8.ipynb) 。

- 注意，你的模型选择需要考虑你的本地硬件能力，该教程的参考显存大小 `CPU Memory > 8GB`。

## 二、文档加载

加载 PDF 文档并将其切分为适当大小的文本块。

```python
from langchain_community.document_loaders import PDFPlumberLoader

file = "DeepSeek_R1.pdf"

# Load the PDF
loader = PDFPlumberLoader(file)
docs = loader.load()

from langchain.text_splitter import RecursiveCharacterTextSplitter
text_splitter = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=0)
all_splits = text_splitter.split_documents(docs)
```

## 三、初始化向量存储

使用 Chroma 数据库存储文档向量，并配置 Ollama 提供的嵌入模型。

```python
from langchain_chroma import Chroma
from langchain_ollama import OllamaEmbeddings

local_embeddings = OllamaEmbeddings(model="nomic-embed-text")

vectorstore = Chroma.from_documents(documents=all_splits, embedding=local_embeddings)
```

## 四、构建 Chain 表达式

设置模型和提示模板，构建处理链。

```python
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_ollama import ChatOllama

model = ChatOllama(
    model="deepseek-r1:1.5b",
)

prompt = ChatPromptTemplate.from_template(
    "Summarize the main themes in these retrieved docs: {docs}"
)

# 将传入的文档转换成字符串的形式
def format_docs(docs):
    return "\n\n".join(doc.page_content for doc in docs)


chain = {"docs": format_docs} | prompt | model | StrOutputParser()

question = "What is the purpose of the DeepSeek project?"

docs = vectorstore.similarity_search(question)

chain.invoke(docs)
```

## 五、带有检索的 QA

整合检索和问答功能。

```python
from langchain_core.runnables import RunnablePassthrough

RAG_TEMPLATE = """
You are an assistant for question-answering tasks. Use the following pieces of retrieved context to answer the question. If you don't know the answer, just say that you don't know. Use three sentences maximum and keep the answer concise.

<context>
{context}
</context>

Answer the following question:

{question}"""

rag_prompt = ChatPromptTemplate.from_template(RAG_TEMPLATE)

retriever = vectorstore.as_retriever()

qa_chain = (
    {"context": retriever | format_docs, "question": RunnablePassthrough()}
    | rag_prompt
    | model
    | StrOutputParser()
)

question = "What is the purpose of the DeepSeek project?"

# Run
qa_chain.invoke(question)
```

## 本节小结

本教程用四个步骤实现了完整的本地 RAG 系统：

1. **文档处理**：PDFPlumberLoader 加载 PDF，RecursiveCharacterTextSplitter 分块；
2. **向量存储**：Chroma + Ollama 嵌入模型（`nomic-embed-text`）建立向量库；
3. **Chain 构建**：提示模板 + `ChatOllama(model="deepseek-r1:1.5b")` 组成处理链；
4. **RAG 实现**：整合检索与问答，基于文档内容回答用户问询。

实践建议：多尝试不同的模型和参数配置，找到适合自己场景的组合。

> 提示：用 streamlit 或 FastAPI 可将本地 RAG 部署为 Web 服务。仓库提供了 [`app.py`](https://github.com/datawhalechina/handy-ollama/blob/main/notebook/C7/DeepSeek_R1_RAG/app.py)，直接运行即可启动 Web 服务（参考 [Build a RAG System with DeepSeek R1 & Ollama](https://apidog.com/blog/rag-deepseek-r1-ollama/)）。运行前需先启动 Ollama 服务。
