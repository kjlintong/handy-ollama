# Ollama OpenAI 兼容接口

> **版本基线**：Ollama 0.17.x（实测通过）
> **章节定位**：OpenAI 兼容接口是**所有 Harness、框架对接 Ollama 的事实标准**。掌握它，等于掌握"任意 OpenAI SDK 应用 + 本地模型"的万能钥匙。

## 一、为什么这个接口如此重要

几乎所有的 Agent 工具（Claude Code、Codex CLI、DeepSeek Harness、OpenCode…）、框架（LangChain、LlamaIndex、LiteLLM…）和应用（Open WebUI、Dify、n8n…）都实现了 OpenAI 客户端协议。

Ollama 原生提供 OpenAI 兼容端点 `http://localhost:11434/v1`，这意味着：

- **零改造接入**：任何"填一个 Base URL + API Key"就能用的工具，直接把 Base URL 填成 `http://localhost:11434/v1`、Key 随便填（如 `ollama`）即可；
- **一套代码两处跑**：本地用 Ollama、云端用 OpenAI，代码完全不变，只换 Base URL；
- **屏蔽底层差异**：工具的开发者不需要为 Ollama 单独写适配器。

> 一句话：**Ollama 的 `/v1` 端点把它"伪装"成了 OpenAI 服务**，而全世界都在说 OpenAI 协议。

## 二、端点一览（实测通过）

| OpenAI 端点 | Ollama 兼容实现 | 用途 |
|---|---|---|
| `GET /v1/models` | ✅ 实测 | 列出本地模型 |
| `POST /v1/chat/completions` | ✅ 实测 | 对话补全（**最常用**） |
| `POST /v1/completions` | ✅ | 文本补全（旧接口） |
| `POST /v1/embeddings` | ✅ 实测 | 文本嵌入 |
| `POST /v1/chat/completions`（带 tools） | ✅ | 工具调用（见[第3节](./3.%20Tool%20Calling%20API.md)） |

## 三、快速上手（实测示例）

### 3.1 列出模型

```bash
curl http://localhost:11434/v1/models
```

实测返回（节选）：

```json
{
  "object": "list",
  "data": [
    {"id": "qwen3:8b-64k", "object": "model", "owned_by": "ollama"},
    {"id": "bge-m3:latest", "object": "model", "owned_by": "ollama"}
  ]
}
```

### 3.2 对话补全

```bash
curl http://localhost:11434/v1/chat/completions -d '{
  "model": "qwen3:8b-64k",
  "messages": [{"role": "user", "content": "用一句话介绍 Ollama"}],
  "stream": false
}'
```

实测返回（节选）：

```json
{
  "id": "chatcmpl-xxx",
  "object": "chat.completion",
  "choices": [{
    "index": 0,
    "message": {"role": "assistant", "content": "Ollama 是一个开源工具，允许用户在本地高效部署和运行大型语言模型……"},
    "finish_reason": "stop"
  }],
  "usage": {"prompt_tokens": 16, "completion_tokens": 286, "total_tokens": 302}
}
```

响应结构完全兼容 OpenAI 规范：`choices[0].message.content` 取正文，`usage` 提供 token 统计。

### 3.3 Python（openai SDK）实测风格示例

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:11434/v1",  # 唯一需要改的地方
    api_key="ollama",                       # 任意非空字符串即可
)

resp = client.chat.completions.create(
    model="qwen3:8b",
    messages=[{"role": "user", "content": "你好"}],
)
print(resp.choices[0].message.content)
```

> 若本机 Ollama 开启在非默认地址（如局域网/WSL 场景），把 `base_url` 换成对应地址即可，见 [C2.5 WSL 小节](../C2/2.%20Ollama%20在%20Windows%20下的安装与配置.md)。

### 3.4 JavaScript（openai npm 包）

```javascript
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "http://localhost:11434/v1",
  apiKey: "ollama",
});

const resp = await client.chat.completions.create({
  model: "qwen3:8b",
  messages: [{ role: "user", content: "你好" }],
});
console.log(resp.choices[0].message.content);
```

### 3.5 嵌入（RAG 场景）

```bash
curl http://localhost:11434/v1/embeddings -d '{
  "model": "bge-m3",
  "input": "测试嵌入"
}'
```

实测返回 `data[0].embedding` 为 1024 维向量（以 bge-m3 为例），与 OpenAI `text-embedding-3-*` 的用法一致。

## 四、常见坑与提示

1. **API Key 随意**：Ollama 不校验 Key，填 `ollama` 或任意字符串都行，但**不要留空**（部分 SDK 会报错）；
2. **模型名要用本地存在的**：`model` 字段必须是 `ollama list` 里有的名字（如 `qwen3:8b`），云端模型名在这里不存在；
3. **`/v1/completions` 与 `prompt`**：部分老 SDK 用文本补全接口，Ollama 同样支持；
4. **`num_ctx` 等高级参数**：OpenAI 兼容接口支持通过 `extra_body={"options": {...}}`（Python SDK）透传 Ollama 特有参数，如上下文长度；
5. **CORS**：浏览器端调用跨域受限时，设置 `OLLAMA_ORIGINS=*`。

## 五、与原生 REST API 如何选择

| 场景 | 推荐接口 |
|---|---|
| Agent 工具 / 框架 / SDK 对接 | **OpenAI 兼容接口**（通用） |
| 需要 Ollama 特有能力（流式细节、options 透传、keep_alive） | 原生 `/api/*` |
| 命令行快速验证 | 原生 `/api/generate`、`/api/chat` |
| Tool Calling | 两者都支持（见下一节） |

## 本章小结

- `http://localhost:11434/v1` 让 Ollama **无缝接入所有 OpenAI 生态工具**，是 Harness 集成的桥梁；
- 四个端点全部实测可用：models / chat/completions / completions / embeddings；
- 对接口诀：**Base URL 换成本地、Key 随便填、模型名用本地的**。
