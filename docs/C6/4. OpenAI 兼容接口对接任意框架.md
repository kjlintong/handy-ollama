# OpenAI 兼容接口对接任意框架

> **版本基线**：Ollama 0.17.x（本章示例实测通过）
> **章节定位**：万能钥匙——任何支持 OpenAI SDK 的框架，都能用「改 base_url」这一招对接本地 Ollama。**学会这一章，等于学会了对接绝大多数框架。**

## 一、核心思想

前面章节反复强调：Ollama 的 `http://localhost:11434/v1` 实现了 OpenAI 兼容接口。因此：

> **凡是"填一个 OpenAI API 地址就能用"的框架/工具，都可以把地址指向本地 Ollama，模型立刻变成本地模型。**

对接三要素（对任何框架都一样）：

1. `base_url` / `baseURL` → `http://localhost:11434/v1`
2. `api_key` → 任意非空字符串（如 `ollama`，本地不校验）
3. `model` → 本地已安装的模型名（`ollama list` 查看）

## 二、LangChain（实测）

```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    base_url="http://localhost:11434/v1",  # 指向 Ollama
    api_key="ollama",
    model="qwen3:8b",
    temperature=0.2,
)

answer = llm.invoke("用一句话介绍 LangChain")
print(answer.content)
```

实测输出（本书环境：Ollama 0.17.7 + qwen3:8b-64k）：

```
LangChain 是一个用于构建和管理语言模型应用的框架，通过提供工具和模块化组件，
帮助开发者高效整合模型、处理文本数据并实现复杂的交互流程。
```

## 三、LlamaIndex

```python
from llama_index.llms.openai import OpenAI

llm = OpenAI(
    model="qwen3:8b",
    api_base="http://localhost:11434/v1",
    api_key="ollama",
)
```

> 注意 LlamaIndex 的参数名是 `api_base`（不是 `base_url`）。

## 四、LiteLLM（统一网关）

LiteLLM 是"百模型统一网关"，把 Ollama 注册为 provider 后，下游所有工具连 LiteLLM 即可：

```python
from litellm import completion

resp = completion(
    model="ollama/qwen3:8b",   # provider/模型 前缀
    api_base="http://localhost:11434",
    messages=[{"role": "user", "content": "你好"}],
)
print(resp.choices[0].message.content)
```

## 五、其他常见框架对接速查

| 框架/工具 | 配置方式 |
|---|---|
| OpenAI Python SDK | `OpenAI(base_url="http://localhost:11434/v1", api_key="ollama")` |
| OpenAI JS SDK | `new OpenAI({ baseURL: ".../v1", apiKey: "ollama" })` |
| LangChain.js | `new ChatOpenAI({ baseURL: ".../v1", apiKey: "ollama" })` |
| Spring AI | `spring.ai.openai.base-url=.../v1`（OpenAI 兼容配置） |
| Haystack | `OpenAIChatGenerator(api_base_url=".../v1")` |
| Vercel AI SDK | `OpenAI({ baseURL: ".../v1" })` |
| Open WebUI / Dify / n8n | UI 里选 OpenAI 兼容，填 base_url（见[第12章](../C12)） |

## 六、注意事项

1. **模型名**：必须是本地已安装的（`ollama list`），不能用"gpt-4o"这种云端名；
2. **高级参数**：OpenAI 兼容接口屏蔽了 Ollama 特有参数（如 `num_ctx`）。需要透传时，Python SDK 用 `extra_body={"options": {...}}`：
   ```python
   resp = client.chat.completions.create(
       model="qwen3:8b",
       messages=[...],
       extra_body={"options": {"num_ctx": 32768}},   # 透传 Ollama 参数
   )
   ```
3. **工具调用**：OpenAI 兼容接口的 `tools` 参数与本地 Tool Calling 兼容（见[第4章](../C4/3.%20Tool%20Calling%20API.md)），所以 **LangChain/LlamaIndex 的 Agent 组件可以直接用本地模型**；
4. **超时与并发**：本地模型推理速度慢于云端，框架默认超时可能过短，酌情调大；并发受 `OLLAMA_NUM_PARALLEL` 限制。

## 本章小结

- 万能对接法：**改 base_url + 假 api_key + 本地模型名**；
- LangChain / LlamaIndex / LiteLLM / Spring AI / Haystack / Vercel AI SDK 全部适用（本章 LangChain、LlamaIndex 已实测）；
- 需要 Ollama 特有参数时用 `extra_body={"options": ...}` 透传；
- 框架的 Agent 组件（工具调用）也能直接用本地模型。
