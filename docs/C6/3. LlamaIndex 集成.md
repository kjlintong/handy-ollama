# LlamaIndex 集成

> **版本基线**：Ollama 0.17.x + llama-index-llms-ollama（本章示例实测通过）
> **章节定位**：LlamaIndex 是 RAG/知识库领域的主流框架。掌握「Ollama 作为 LLM + Embedding 双后端」接入 LlamaIndex，是第 10 章本地 RAG 的基础。

## 一、LlamaIndex 与 Ollama 的关系

- **LlamaIndex**：面向"文档 → 索引 → 检索 → 问答"的数据框架，擅长 RAG；
- **Ollama**：本地模型底座，同时提供**生成（LLM）**与**嵌入（Embedding）**两种能力；
- **组合方式**：LlamaIndex 消费 Ollama 的两种能力，一套本地服务搞定整个 RAG 流水线。

## 二、环境准备

```bash
pip install llama-index-core llama-index-llms-ollama llama-index-embeddings-ollama
```

## 三、Ollama 作为 LLM（生成端）

```python
from llama_index.llms.ollama import Ollama

llm = Ollama(
    model="qwen3:8b",
    base_url="http://localhost:11434",   # 默认即此地址, 可省略
    temperature=0.2,
)

resp = llm.complete("用一句话介绍 LlamaIndex")
print(resp)
```

实测输出（本书环境：Ollama 0.17.7 + qwen3:8b-64k）：

```
LlamaIndex是一个用于构建和管理大型语言模型应用的框架，
提供文档处理、查询和推理工具，帮助开发者高效构建智能对话和信息检索系统。
```

## 四、Ollama 作为 Embedding（嵌入端）

RAG 需要把文档切成块并向量化。Ollama 的嵌入模型（如 `bge-m3`，1024 维）直接接入：

```python
from llama_index.embeddings.ollama import OllamaEmbedding

embed_model = OllamaEmbedding(
    model_name="bge-m3",
    base_url="http://localhost:11434",
)

vec = embed_model.get_text_embedding("Ollama 是什么?")
print(f"向量维度: {len(vec)}")   # 实测: 1024
```

> 先确保已拉取嵌入模型：`ollama pull bge-m3`。

## 五、组合：文档问答（最小 RAG）

把 LLM 与 Embedding 都指向 Ollama，就能搭建全本地 RAG：

```python
from llama_index.core import VectorStoreIndex, SimpleDirectoryReader
from llama_index.llms.ollama import Ollama
from llama_index.embeddings.ollama import OllamaEmbedding
from llama_index.core import Settings

# 双后端都指向本地 Ollama
Settings.llm = Ollama(model="qwen3:8b", base_url="http://localhost:11434")
Settings.embed_model = OllamaEmbedding(model_name="bge-m3", base_url="http://localhost:11434")

# 读取本地文档目录并建索引
documents = SimpleDirectoryReader("./data").load_data()
index = VectorStoreIndex.from_documents(documents)

# 检索 + 生成
query_engine = index.as_query_engine()
answer = query_engine.query("这份文档的核心观点是什么?")
print(answer)
```

完整的多文档 RAG 实战（含分块、检索调优、GraphRAG）见[第10章](../C10)。

## 六、也可以用 OpenAI 兼容接口

LlamaIndex 同样支持 OpenAI 兼容方式对接（`llama-index-llms-openai` + `base_url` 指向 `/v1`），写法与 [4. OpenAI 兼容接口对接任意框架](./4.%20OpenAI%20兼容接口对接任意框架.md) 一致——两种方式二选一：

| 方式 | 包 | 优点 |
|---|---|---|
| 原生 Ollama 集成 | `llama-index-llms-ollama` | 参数直达（num_ctx 等），无中间层 |
| OpenAI 兼容 | `llama-index-llms-openai` + base_url | 与云端切换零改造 |

## 本章小结

- LlamaIndex 消费 Ollama 的**生成 + 嵌入**双能力，是本地 RAG 的标准组合；
- `Ollama` 与 `OllamaEmbedding` 两个类即完成接入，`Settings` 全局注册；
- 嵌入模型推荐 `bge-m3`（1024 维，中英文俱佳）；
- 原生集成与 OpenAI 兼容两种姿势按需选择。
