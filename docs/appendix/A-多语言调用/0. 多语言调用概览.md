## 二、语言无关的统一方案：OpenAI 兼容接口

如果不想为每种语言各写一套 SDK 调用，**所有语言都有 OpenAI 官方 SDK**，配合 Ollama 的 `/v1` 端点即可统一：

| 语言 | OpenAI SDK | 本地用法（Base URL） |
|---|---|---|
| Python | `openai` | `http://localhost:11434/v1` |
| JavaScript | `openai` (npm) | 同上 |
| Java | `openai-java` | 同上 |
| Go | `openai-go`（社区） | 同上 |
| C++ | `openai-cpp`（社区） | 同上 |

配置方法完全一致：`base_url` 指向 `/v1`、`api_key` 随便填、`model` 用本地模型名。详见 [2. OpenAI 兼容接口](../../C4/2.%20OpenAI%20兼容接口.md)。

## 三、选型建议

- **做 Agent / RAG / 自动化脚本** → Python（生态最全，本书示例均以 Python 为主）；
- **做 Web / 前端应用** → JavaScript；
- **企业级后端** → Java（Spring AI 对 Ollama 有原生支持）；
- **需要嵌入现有 C++/Go 服务** → 用各自官方 SDK 或 OpenAI 兼容接口；
- **多语言团队统一维护** → 全部走 OpenAI 兼容接口，代码风格一致、可平滑切换云端。
