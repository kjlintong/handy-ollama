# WebUI 部署 Ollama 可视化对话界面

> **版本基线**：Ollama 0.17.x + Open WebUI（易变 UI 细节以官方文档与 living-docs 为准）
> **本节定位**：两种可视化对话界面部署方式——Node.js 跑轻量版（ollama-webui-lite）、Docker 跑官方版（open-webui）。

参考仓库：[ollama-webui-lite](https://github.com/ollama-webui/ollama-webui-lite)

## 一、使用 Node.js 部署

### 安装 Node.js

下载并安装 `Node.js` 工具：https://nodejs.org/zh-cn/download

![](../images/C6-2-1.png)

设置镜像源，例如使用如下的镜像源。

```bash
npm config set registry https://mirrors.cloud.tencent.com/npm/
```

### 克隆 ollama-webui 仓库

在终端中克隆 ollama-webui 仓库，切换 ollama-webui 代码的目录。

```bash
git clone https://github.com/ollama-webui/ollama-webui-lite.git
cd ollama-webui-lite
```

### 安装依赖

在终端中安装依赖。

```bash
npm ci
```

![](../images/C6-2-2.png)

### 运行

```bash
npm run dev
```

![](../images/C6-2-3.png)

点击 `http://localhost:3000/` ，打开页面。

![](../images/C6-2-4.png)


## 二、使用 Docker 部署

本小节在 Windows 下使用 Docker 部署 open-webui 。

参考教程 [Ollama 在 Windows 下的安装与配置](../C2/2.%20Ollama%20在%20Windows%20下的安装与配置.md)，提前安装 Ollama。在终端使用以下命令，拉取 `ghcr.io/open-webui/open-webui:main` 镜像并运行。

```bash
docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -v open-webui:/app/backend/data --name open-webui --restart always ghcr.io/open-webui/open-webui:main
```

命令终端出现以下结果，表示运行成功。

![](../images/C6-2-5.png)

命令运行成功后，在 Docker 的 Container 下会出现 `open-webui`，如下图所示。

![](../images/C6-2-6.png)

之后点击端口访问，如下图所示。也可以直接在浏览器输入 `http://localhost:3000/` 访问。

![](../images/C6-2-7.png)

打开后会出现登录到 Open WebUI，只需注册一下账号即可。

![](../images/C6-2-8.png)

![](../images/C6-2-9.png)

选择模型之后，就可以开始对话了。

> 生产环境建议把镜像 tag 从 `main`（滚动更新）固定到具体版本，避免意外升级。

## 本节小结

- 两种部署：Node.js 跑 lite 版（轻量、适合开发体验）、Docker 跑官方版（数据持久化 `-v`、`--restart always` 自动拉起）；
- Docker 关键参数：`--add-host=host.docker.internal:host-gateway` 让容器能访问宿主机的 Ollama；
- 首次使用注册账号，选择模型即可对话。
