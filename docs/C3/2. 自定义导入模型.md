# Ollama 模型管理与自定义 - 自定义导入模型

> **版本基线**：Ollama 0.17.x
> **本章定位**：把本地已有的模型文件（GGUF / Safetensors）或 HuggingFace 上的模型导入 Ollama，转换、量化并运行
> **前置**：[3.3 GGUF 深度解析与量化选型](./3.%20GGUF%20深度解析与量化选型.md)（理解 GGUF 格式与量化级别）、[3.4 Modelfile 高级编写](./4.%20Modelfile%20高级编写.md)（Modelfile 语法）

## 一、导入方式总览

Ollama 支持三种方式把模型导入本地：

| 方式 | 适用场景 | 流程 |
|---|---|---|
| 从 GGUF 导入 | 已有 `.gguf` 文件（HuggingFace 上最常见） | 下载 → 写 Modelfile → `ollama create` |
| 从 PyTorch / Safetensors 导入 | 模型是官方 HF 权重格式 | 部分架构可直接导入 |
| 用 llama.cpp 转换后导入 | 任意 HF 模型 | 下载 → 转 GGUF → 量化 → `ollama create` |

本章代码及示例文件在 `notebook/C3` 目录（`1.从GGUF直接导入` / `2.safetensors导入` / `3.模型直接导入`）。

## 二、从 GGUF 导入

GGUF（GPT-Generated Unified Format）是 llama.cpp 生态的统一模型文件格式，一个文件内打包了权重、超参数、分词器与元数据，是本地推理的事实标准（格式原理见 [3.3 GGUF 深度解析](./3.%20GGUF%20深度解析与量化选型.md)）。**只要拿到 `.gguf` 文件，就能导入 Ollama。**

以 Qwen2-0.5B 为例：

1. **下载 `.gguf` 文件**

   > 下载链接：<https://huggingface.co/RichardErkhov/Qwen_-_Qwen2-0.5B-gguf/resolve/main/Qwen2-0.5B.Q3_K_M.gguf?download=true>

   将文件放到工作目录，可参考以下目录结构：

   ```bash
   ├── 1.从gguf直接导入/
   │   ├── main.ipynb
   │   ├── Modelfile
   │   └── Qwen2-0.5B.Q3_K_M.gguf
   ├── 2.safetensors导入/
   │   ├── llama-3-8b-bnb-4bit/
   │   ├── main.ipynb
   │   └── Modelfile
   └── 3.模型直接导入/
       ├── llama.cpp/
       ├── Qwen-0.5b/
       ├── main.ipynb
       ├── Modelfile
       └── Qwen_instruct_0.5b.gguf
   ```

   > [!TIP]
   > 本节代码与文件在 `notebook/C3` 目录中，如果模型文件不知放哪，参考 [notebook/C3](https://github.com/datawhalechina/handy-ollama/blob/main/notebook/C3)。

2. **创建 Modelfile 文件**

   ```dockerfile
   FROM ./Qwen2-0.5B.Q3_K_M.gguf
   ```

3. **在 Ollama 中创建模型**

   > [!NOTE]
   > 必须在 Modelfile 所在的目录下运行！

   ```bash
   ollama create mymodel -f Modelfile
   ```

4. **运行模型**

   ```bash
   ollama run mymodel
   ```

   ![alt text](../images/C3-1-1.png)

## 三、从 PyTorch / Safetensors 导入

Safetensors 是 HuggingFace 推出的安全高效的权重存储格式。**如果你的模型属于以下架构之一，可以直接用 Modelfile 导入 Ollama**（Ollama 会尝试自动转换）：

- `LlamaForCausalLM`
- `MistralForCausalLM`
- `GemmaForCausalLM`

> 这部分能力社区仍在完善中，示例流程仅供参考，不保证所有版本都能成功，详情以[官方文档](https://docs.ollama.com/import)为准。也可以把 Safetensors 先转成 GGUF 再导入（见第四部分）。

1. **下载模型**（以 llama-3-8b-bnb-4bit 为例）

   ```bash
   pip install huggingface_hub
   ```

   ```python
   from huggingface_hub import snapshot_download

   model_id = "unsloth/llama-3-8b-bnb-4bit"
   snapshot_download(
       repo_id=model_id,
       local_dir="llama-3-8b-bnb-4bit",
       revision="main",
       token="<YOUR_ACCESS_TOKEN>",  # 获取方式见第四部分 4.1
   )
   ```

2. **创建 Modelfile 文件**

   ```dockerfile
   FROM ./llama-3-8b-bnb-4bit
   ```

3. **创建并运行模型**

   ```bash
   ollama create mymodel2 -f Modelfile
   ollama run mymodel2
   ```

## 四、用 llama.cpp 转换导入（任意 HuggingFace 模型）

对于 Ollama 不能直接转换的架构，标准路径是：**下载模型 → 用 llama.cpp 转成 GGUF → 量化 → 导入 Ollama**。整个流程分为四步：

1. 从 HuggingFace 下载模型；
2. 使用 llama.cpp 转换为 GGUF 格式；
3. 使用 llama.cpp / Ollama 进行量化；
4. （可选）上传到 HuggingFace 分享。

### 4.1 从 HuggingFace 下载模型

**方法一：Python 脚本下载（推荐，可断点续传）**

先去 HuggingFace 个人设置页（<https://huggingface.co/settings/tokens>）创建一个 `ACCESS_TOKEN`：

![alt text](../images/C3-1-2.png)

![alt text](../images/C3-1-3.png)

![alt text](../images/C3-1-4.png)

```bash
pip install huggingface_hub
```

```python
from huggingface_hub import snapshot_download

model_id = "Qwen/Qwen1.5-0.5B"  # HuggingFace 模型名
snapshot_download(
    repo_id=model_id,
    local_dir="Qwen-0.5b",
    revision="main",
    token="<YOUR_ACCESS_TOKEN>",
)
```

模型文件较大（按 GB 计），下载耗时较长，耐心等待。

**方法二：HuggingFace CLI 下载**

```bash
# macOS / Linux
curl -LsSf https://hf.co/cli/install.sh | bash

# Windows (PowerShell)
powershell -ExecutionPolicy ByPass -c "irm https://hf.co/cli/install.ps1 | iex"
```

安装完成后：

```bash
hf download Qwen/Qwen1.5-0.5B
```

![alt text](../images/C3-1-13.png)

![alt text](../images/C3-1-14.png)

### 4.2 使用 llama.cpp 转换为 GGUF

llama.cpp 是 GGML 生态的 C/C++ 推理引擎，`convert_hf_to_gguf.py` 脚本可以把 HuggingFace 权重转换为 GGUF 格式：

```bash
git clone https://github.com/ggerganov/llama.cpp.git
cd llama.cpp
pip install -r requirements.txt
python convert_hf_to_gguf.py -h   # 确认转换脚本就绪
```

![alt text](../images/C3-1-5.png)

把上一步下载的模型转换为 GGUF（f16 精度）：

```bash
python convert_hf_to_gguf.py ../Qwen-0.5b --outfile Qwen_instruct_0.5b.gguf --outtype f16
```

![alt text](../images/C3-1-6.png)

转换只需几秒钟，完成后 llama.cpp 目录下多了一个 `Qwen_instruct_0.5b.gguf` 文件。

### 4.3 量化并导入 Ollama

原始 f16 权重体积较大（8B 模型约 16 GB），量化可以成倍缩小体积（量化原理与级别选择见 [3.3 GGUF 深度解析](./3.%20GGUF%20深度解析与量化选型.md)）。把 GGUF 文件移到工作目录，创建 Modelfile：

```dockerfile
FROM ./Qwen_instruct_0.5b.gguf
```

用 `ollama create -q` 在创建时直接指定量化级别（这里用社区主流选择 Q4_K_M）：

```bash
ollama create -q Q4_K_M mymodel3 -f ./Modelfile
```

![alt text](../images/C3-1-7.png)

量化完成即创建成功，运行方式同第二部分。

### 4.4 上传到 HuggingFace（可选）

如果想把本地模型分享出去，可以用 `huggingface_hub` 上传。**上传需要 Write 权限的 token**，并把 `model_id` 改成自己的账号名：

```python
from huggingface_hub import HfApi
import os

api = HfApi()
HF_ACCESS_TOKEN = "<YOUR_HF_WRITE_ACCESS_TOKEN>"
# 例如 model_id = "your_hf_name/QWEN-0.5b"
model_id = "your_hf_name/QWEN-0.5b"

api.create_repo(model_id, exist_ok=True, repo_type="model", token=HF_ACCESS_TOKEN)

for file in os.listdir():
    if file.endswith(".gguf"):
        api.upload_file(
            repo_id=model_id,
            path_in_repo=file,
            path_or_fileobj=f"{os.getcwd()}/{file}",
            repo_type="model",
            token=HF_ACCESS_TOKEN,
        )
```

![alt text](../images/C3-1-8.png)

上传完成后就能在自己的 HuggingFace 仓库看到模型了。

## 本节小结

- 三种导入方式：GGUF 直接导入、Safetensors 直接导入、llama.cpp 转换后导入；
- 从 GGUF 导入只需 `FROM ./xxx.gguf` + `ollama create`；
- 任意 HF 模型：下载 → `convert_hf_to_gguf.py` 转 GGUF → `ollama create -q` 量化导入；
- 量化级别选型见 [3.3](./3.%20GGUF%20深度解析与量化选型.md)；创建后的模型定制（系统提示词、采样参数）见 [3.4 Modelfile 高级编写](./4.%20Modelfile%20高级编写.md)。
